# File Upload & Visualization Tool for A4A

A React application that allows users to upload JSON files, extract data, customize traces, and visualize them using Plotly.js. This project works alongside [A4A](https://github.com/matheospower/a4a) to enhance visualization capabilities.

## 🚀 Features

- 📁 Upload JSON files or fetch analysis results via GraphQL
- 📊 Supports various chart types: Line, Bar, Pie, Radar (ScatterPolar), Violin, Box, Histogram, Heatmap
- 🎨 Customize trace appearance: color, opacity, fill, orientation, bar mode, etc.
- ✏️ Edit chart titles, axis labels, and split/group data by any field
- 💾 Save, update, and delete visualizations (including layout references)
- 🔖 Save individual trace configurations as **templates**
- 🧠 Add `templateName` for easy identification and reuse
- ✅ When applying a template, it overrides config **without linking to its ID**
- ❌ Saved visualizations reference only **non-bookmarked layouts**
- 🔐 Bookmarked layouts are never modified by visualizations (template isolation)
- 🔎 View, apply, and manage templates via dropdown

## Installation

### Prerequisites

- **Node.js** (Ensure you have Node.js installed: [Download here](https://nodejs.org/))
- **npm** or **yarn** (Package manager)
- **A4A Backend** (Follow the setup instructions for [A4A](https://github.com/matheospower/a4a))

### Steps

1. Clone this repository:
   ```sh
   git clone https://github.com/your-username/file-upload-visualization.git
   cd file-upload-visualization
   ```
2. Install dependencies:
   ```sh
   npm install
   # or
   yarn install
   ```
3. Start the development server:
   ```sh
   npm start
   # or
   yarn start
   ```
4. Ensure A4A is running and properly configured.

## Usage

1. Open the application in your browser (`http://localhost:3000`).
2. Upload a JSON file containing the data to be visualized.
3. Choose axes (X, Y, Z), chart type, and optional grouping (split by)
4. Customize traces using the right-side panel (color, opacity, fill, etc.)
4. View the live plot generated by **Plotly.js**.
5. Save the visualization for later
6. Optionally:

Save an individual trace as a template with a templateName

Apply saved templates to any trace

Update or delete saved templates
7. Load, update, or delete saved visualizations

## JSON File Format

The uploaded JSON file should be structured as follows:

```json
{
  "data": {
    "resultRequest": [
      {
        "results": [
          { "x": 1, "y": 10, "group": "A" },
          { "x": 2, "y": 15, "group": "A" },
          { "x": 1, "y": 5,  "group": "B" }
        ]
      }
    ]
  }
}

```

## Design Choices

- When you save a visualization, all associated trace configurations are saved as new layouts (if not bookmarked).es
- Saved visualizations do not reference trace templates (bookmarked layouts).
- When you apply a template, it overrides the trace config but keeps the original ID — this ensures the visualization remains self-contained.
- Template updates are done via the Update button only when a template is selected from the dropdown.
- Deleting a visualization also deletes its associated layouts (unless bookmarked).
