# File Upload & Visualization Tool for A4A

A React application that allows users to upload JSON files, extract data, customize traces, and visualize them using Plotly.js. This project works alongside [A4A](https://github.com/AndreasHadjisavvas99/a4a) to enhance visualization capabilities.

## Features

- Upload JSON files to extract and visualize data
- Customize chart titles, axes labels, and trace configurations
- Supports multiple chart types (Line, Bar, Pie, etc.)
- Advanced customization for individual traces
- Save visualization configurations using GraphQL mutations
- Seamless integration with A4A for extended functionalities

## Installation

### Prerequisites

- **Node.js** (Ensure you have Node.js installed: [Download here](https://nodejs.org/))
- **npm** or **yarn** (Package manager)
- **A4A Backend** (Follow the setup instructions for [A4A](https://github.com/AndreasHadjisavvas99/a4a))

### [Steps](https://github.com/AndreasHadjisavvas99/a4a)

1. [Clone this repository:](https://github.com/AndreasHadjisavvas99/a4a)
   ```sh
   git clone https://github.com/your-username/file-upload-visualization.git
   cd file-upload-visualization
   ```
2. Install dependencies:
   ```sh
   npm install
   # or
   yarn install
   ```
3. Start the development server:
   ```sh
   npm start
   # or
   yarn start
   ```
4. Ensure A4A is running and properly configured.

## Usage

1. Open the application in your browser (`http://localhost:3000`).
2. Upload a JSON file containing the data to be visualized.
3. Customize chart attributes (titles, axes labels, colors, trace configurations, etc.).
4. View the live plot generated by **Plotly.js**.
5. Save and manage visualization settings via GraphQL API and A4A.

## JSON File Format

The uploaded JSON file should be structured as follows:

```json
{
  "data": [
    {
      "name": "Trace 1",
      "x": [1, 2, 3, 4, 5],
      "y": [10, 15, 7, 20, 25]
    },
    {
      "name": "Trace 2",
      "x": [1, 2, 3, 4, 5],
      "y": [5, 10, 15, 10, 5]
    }
  ],
  "layout": {
    "title": "Sample Visualization",
    "xaxis": { "title": "X Axis" },
    "yaxis": { "title": "Y Axis" }
  }
}
```
